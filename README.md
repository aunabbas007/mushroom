# Mushroom Classification — Random Forest

A tabular classification project that predicts the dataset label (edible or poisonous) using a Random Forest classifier.

> **Safety note:** This is a machine-learning demonstration on a public dataset. Never use this model or its predictions to decide whether a real mushroom is safe to eat.

## Dataset
- Source: [UCI Mushroom Classification on Kaggle](https://www.kaggle.com/datasets/uciml/mushroom-classification)
- 8,124 rows
- 22 categorical features
- Target: `e` (edible) or `p` (poisonous)
- The `?` values in `stalk-root` are handled during preprocessing.

Download `mushrooms.csv` and place it beside the scripts.

## Train
```bash
pip install pandas numpy matplotlib seaborn scikit-learn
python train.py
```

The documented training workflow label-encodes categorical columns, fits a 100-tree Random Forest, reports classification metrics, and saves the trained model and diagnostic plots.

## Predict
```bash
python model.py
```

The prediction script loads the generated model artifact and evaluates sample inputs.

## Generated artifacts
- `mushroom_rf_model.pkl`
- `confusion_matrix.png`
- `feature_importance.png`

These are generated by the training workflow; follow the script output for the exact paths.

## Stack
Python · Pandas · NumPy · scikit-learn · Matplotlib · Seaborn

## Evaluation note
The original project reports near-100% metrics. The odor feature is highly predictive in this dataset, but such results should be interpreted in the context of the dataset and split. Validate for leakage and report a held-out test result before making performance claims.
